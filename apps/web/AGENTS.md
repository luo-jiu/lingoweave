# 前端开发约定

先遵守根目录 `AGENTS.md`。

- 使用 React 函数组件、TypeScript 与 Vite。初始工程使用普通 CSS，按实际需求再引入组件库或状态管理。
- 远程数据通过 `/api` 同源访问；开发时由 Vite 代理，不把后端地址散落在组件里。
- 使用 `@lingoweave/contracts` 校验响应。加载、失败、取消与重试应有明确反馈。
- 表单、按钮、标题与状态提示使用语义化 HTML，支持键盘、清楚的焦点样式和窄屏布局。
- 展示服务端事实；未实现的学习功能明确说明，不使用虚构学习数据或无行为按钮。
- 不在前端计算权威复习状态或保存唯一学习记录；答案、帮助与测验状态由后端确认。
- 不将 Node.js 模块、凭据或参考答案放进客户端公共数据。
- 校验：在仓库根目录运行 `pnpm typecheck`、`pnpm lint`、`pnpm build`，并在浏览器检查对应交互。
