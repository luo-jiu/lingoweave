# 后端开发约定

先遵守根目录 `AGENTS.md`。

## 基础结构

- 使用 Node.js、TypeScript、Fastify 与 ESM。
- `app.ts` 组装应用并返回 Fastify 实例，不在导入时监听端口。
- `index.ts` 读取配置、启动监听与处理退出信号；环境配置集中校验。
- HTTP 路由保持简洁。后续业务规则进入独立服务或领域模块，不塞进路由处理器。
- 前端与 MCP 工具将来共用业务服务，不能各写一套评分、提交或调度逻辑。

## 接口与保存

- 接口统一使用 `/api` 前缀，共享数据结构放在 `@lingoweave/contracts`。
- 对输入和配置做运行时校验；错误返回稳定结构及请求身份，不泄露堆栈、凭据或原始内部错误。
- 默认监听 `127.0.0.1`。日志保留必要请求信息，不记录学习全文、提示答案或密钥。
- 后续 SQLite 表结构通过迁移管理；已确认保存的业务结果和事件需要可靠提交边界。
- 重试、并发评价与旧题结果必须校验身份和版本；Agent 自然语言不能作为保存成功的回执。
- 生产运行使用编译后的 JavaScript；`tsx` 仅用于本地开发和测试。

## 验证

- 用 `app.inject()` 验证 HTTP 行为，测试结束关闭实例，测试不占用固定端口。
- 覆盖契约、输入错误和真实边界；后续涉及保存时验证事务、幂等与恢复。
- 在根目录运行 `pnpm check`；入口或静态服务变更还需验证构建产物实际启动。
