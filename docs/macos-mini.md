# macOS 悬浮词卡

2026 年 11 月 17 日按 [学习流程与后台评价规则](learning-flow-rules.md) 接入新版原生流程：每词窗口交错、答后核对、三轮首答拼写、复习重学、每日最终完成目标和首页后台评价。源码的原生行为、五条隔离 HTTP 流程、真实模型评价与应用包验收已通过；完整阶段点击和长期使用仍另行观察，不能用旧版本历史验收代替。以下现行流程以 `sliding-window-v2` 为准，迁入的已作答旧组保留原版本。

LingoWeave Mini 是独立的 macOS 应用，源码位于 `apps/macos`。应用出现在 Dock 与 Cmd+Tab 中，点击 Dock 图标或切回应用会唤回上次使用的窗口。关闭词卡后可再次唤回。窗口默认约 360 × 300 点，每次启动默认不置顶，可用标题栏图钉开启。开发版默认进入正常流程首页，首屏显示所选词库、每日新词目标、每组数量、今日模式、到期复习量和今日记录，可直接点右上角的滑杆调整学习计划。「今日记录」旁的小日期显示已加载的本地学习日。今日记录按同一天和实际事件时间跨任务聚合，热力图也在这一天画轮廓。应用常驻时在午夜、系统时间或时区变化、唤醒和回到窗口时核对学习日。每分钟也会核对一次，换日或上次没读到计划时才重新请求。新版“完成新词”采用服务端最终完成投影，只计已结束本组拼写并确认翻译的词，不等待后台评价；复习练习取真实判断、重学或拼写的词，按拼写与释义去重。「翻译点评」的题数按已提交的答案去重，包含正在等待点评的译文。四个月活动热力图默认折叠。底部有复习和新词两个入口，各自显示可开始或可接续的任务。书封外圈表示整本词书的完成比例，旁边显示全书已学词数和总词数。切换等级或排序时仍按整本书统计，自定义词表则按当前词表统计。「学习记录」下的累计学完词数涵盖全部词书，按拼写和释义去重。首页只读取计划和学习记录；明确开始或继续后才创建本次预算，并在材料缺失时准备任务。热力图按日历月展示本月和前三个月，按实际操作日期统计记词、自评、拼写和翻译作答。每日色阶依次为 0、1–49、50–149、150–299 和 300 次及以上。鼠标移到日期格上时，格子旁立即显示日期和当天词数。Review 是练习过的复习词数，New 是完成的新词数，All 是两者的合计。同一类别中重复练习同一词义只计一次。本月还没到的日期用淡色显示。选择复习或新词进入任务，学习中可用房子按钮返回首页，当前题和已保存的输入会保留。

mini 是日常学习的主要界面，计划调整、AI、重点、语音和存储方针见 [mini 学习、AI 与语音方案](mini-ai-learning-plan.md)。2026 年 11 月 13 日已实现学习事实统一、三层计划和缺席恢复，以及 Node AI 任务、聊天工具、词义重点、有限偏好、独立写作与定性反馈。第三步四类任务已分别完成真实 `gpt-6.1-sol` / `xhigh` 与工具保存验证。2026 年 11 月 16 日第四步已实现单词/例句音频、缓存和单条重生成，真实离线 MLX 与隔离 Swift/HTTP 流程已通过。工程检查和真实顾问音频工具已通过，复习预览已验证真实单词/例句播放，其他阶段点击布局与主观听感仍待验收；本轮已补原生单卡默写、独立拼写检验与 FSRS、全局快捷键、包内 Node 与词库计划，最终验收见下。应用内导出恢复和清理本轮暂缓，声音克隆仍在后续范围。

词卡、AI 聊天、阶段菜单和图钉与系统窗口按钮同在标题栏。默认 Control+Option+Space 可唤出或隐藏小窗，菜单栏右键菜单的「全局快捷键」提供 Control+Option+L 或关闭，冲突时显示提示。窗口加宽后可在中间看到应用名。点菜单栏的语织图标可找回被挡住或已隐藏的小窗，右键图标可打开隐藏和退出菜单。界面采用 macOS 的系统浅色和深色外观，按钮沿用系统强调色和对应的文字颜色；滚动区域使用细款浮动滚动条。

应用图标采用蓝绿色圆角底和交织书页，PNG 源文件与 ImageGen 生成提示词放在 `apps/macos/assets/`。打包脚本从源图生成完整标准尺寸的 ICNS，并通过 `CFBundleIconFile` 提供给 Finder、Dock 和应用切换器。

在仓库根目录运行以下命令构建并打开应用。需要 macOS 14 或更新版本和 Swift 6 工具链，本机可用 Xcode Command Line Tools。

```sh
./apps/macos/build-app.sh --open
```

应用生成在 `apps/macos/dist/LingoWeave Mini.app`，之后可以直接双击打开。需要换版本时，先从菜单栏退出正在运行的实例，再打开新构建的应用。

「窗口 → 数据总览…」或 `⌘3` 打开独立的[数据总览](mini/data-overview.md)，可以查看学习与评价记录数量、音频、存储占用，以及在 Finder 打开当前数据目录。

打包时使用所选 macOS SDK 的版本链接。用 macOS 26 或更新 SDK 构建后，在支持 Liquid Glass 的系统上由 AppKit 绘制玻璃质感的关闭、最小化和缩放按钮。应用最低支持 macOS 14。

点击首页书名或从右上角阶段菜单进入「浏览词表」，按当前词表顺序滚动查看，一行显示一个单词和释义。宽窗另列音标；在小窗悬停可查看完整词条。点选一行后，底部朗读和单词聊天针对该词，不用翻卡。只有屏幕实际显示的行计入答案曝光，浏览本身不增加学习完成数或改变复习日期。学习与复习仍使用原有词卡。

在词表右上角点「编辑」可以粘贴自定义单词，浏览内置词书时入口标明「编辑自定义词表」，每行一个，用 Tab 分隔单词和释义。仅含英文的词可浏览，但中文提示拼写需要先补释义，才会纳入每日任务。自定义词表和选中位置保存在本机偏好中。内置词表沿用项目的 30 个基础词。来源与许可见 [词条来源](lexicon-sources.md)。

首页的「今日任务」以书名为主，旁列级别和选词顺序，可由右上角的滑杆按钮调整计划。正常学习日的圆环按当日完成新词数和原定目标绘制；完成当日任务后，图标右下角显示绿色勾，悬停或通过 VoiceOver 可读到「今日任务已完成」。今日记录三栏展示已做的练习，待做数量显示在底部按钮上。「待复习」显示全部到期词数，正常学习的「学新词」显示当天的新词目标。「加练」显示这组实际能学的词数，词书余量不足一组时按余量显示，中途回来仍显示本组总数。折叠的学习记录展示近四个月每周的真实活动。学习日完成新词目标后，或在休息日，仍有可学的词就能主动加练。例如每组 10 词，点一次就多练一组，学到一半可以退出并继续，完成后回到首页还能再选。加练的词照常计入今日记录与后续复习，原定的每日目标保持原值。

学习时长设置、记录和限时暂停已移除。旧计划的分钟字段在数据库第 8 版迁移中清除，因旧时长上限暂停的新流程任务在当前计划允许时恢复。

每日先复习，再开始新词。「每组数量」同时决定复习和新词的分组大小。例如每组 10 词、当天有 23 词到期，会分成 10、10、3 词；每组做完判断、必要的重学和拼写，再接着下一组。首页显示当天待复习总量，小窗顶部显示组号和当前组进度。空间足够时每词一个点，空间紧张时改用细进度条和计数。「只复习」的当天也可单独调整每组数量。

升级时，正在判断的旧大组会将尚未接触的词分到后续小组，保留当前词、已做的判断和获得的提示。已经进入重学或拼写的旧组按原队列做完，小窗同样使用自适应进度。

「每日新词」单独计算，例如每日 50 个新词、每组 20 词，会分成 20、20、10。长期和今日安排都可以设置这两个数。同一天内保留当前组、词卡阶段及已保存的输入。次日的未完成词重新参加当前词书选词，再遇时从完整词卡开始。当前组、目标余量与可继续状态均由 Node 返回。

1. 普通复习先看英文判断记忆。选档后展开释义和已有例句，自动重新读词，结束半秒后读例句；清晰退出判断循环，模糊和遗忘继续在后续轮初见出现。三轮首见仍未清晰的词进入下述三阶段重学，完成后才进入整组拼写。点「完成复习」会接上下一组到期词。单独从「复习」进来，清完就回首页。从新词入口进来，清完后继续当天的起手句式、备课或新词。历史迁移词没有可复用例句时，重学阶段 1 明示“词义提示回忆（暂无例句）”，使用已有释义并保留受支持事实，不编造材料或等待 AI 才能完成复习。
2. 新词使用容量 5 的窗口，每个词分别处于 0（完整词卡）、1（英文例句）、2（英文单词）阶段。客户端和服务端按同一交错规则选择下一词。阶段 0 点击“记住了”立即切词。阶段 1、2 点击“想起来了”或“想不起来”展开完整卡并自动读词、等待半秒、读例句，绿点在想起时立即增加一颗，想不起立即清零并保留核对画面。点击“记错了”立即切词，在后台确认改判并将原词退回 0。其余情况点“下一个”确认升级、退回 0 或出窗。完整卡可打开草稿本。熟悉的新词可在阶段 0 点「已认识」，点击后立即切词。它与正常通过三阶段的词一起等候本组拼写与翻译。复习重学仍需走完三阶段。
3. 新词与复习的总拼写在每轮开始时打乱顺序。当天暂停、重试或重启后保留当轮题序和当前词。每轮首答决定后续队列。输入留空时，按回车即记为错答，输入下划线标红，同时显示正确拼写并读词。首答错误后的订正不增加轮数；订正后正常进入下一词，仅上一轮首答错误的词在下一轮重测。最新一轮首答正确即退出拼写队列，不能因为更早错过又出现。每词最多三轮首答，第三轮仍错时展示正确拼写并允许下一词。正确或订正正确均先停留显示绿色，回车确认前进。真实首答、订正与跳过保留用于后续调度。
4. 新词整组拼写结束后进入独立翻译题。原答先保存，提交后可停留与 AI 讨论；“下一词”或“完成本组”立即进入后续内容，后台评价继续处理。组内题号从 1 开始显示，全部翻译确认后开启下一组。达到今日目标后回首页，尚未完成的窗口成员保留。后台评价不在翻译卡显示转圈；首页“学习评价”展示处理中与失败重试，可点词查看原答、词义/拼写/用法解释、参考译文、当时讨论、规则版本与复习日期变化。

例句与音频在明确开始或继续后的复习期间预取。备课范围使用窗口及当日目标形成的候选储备，新词卡入口等待整个候选池的例句和两类音频就绪；独立写作题优先于后续储备补齐。缺少必要材料时显示四步准备页，已保存材料和音频缓存复用。真实原文在译文前显示书名，不显示“原创例句”标签。标题栏菜单、模式分隔线和已确认的系统菜单展开方式本轮保持不变；通用撤销和常驻“已按学习规则保存”提示从记忆词卡移除，保存失败仍明确显示。

新建及允许迁移的未作答组采用 `sliding-window-v2`，窗口为 `interleaved-v2`，拼写为 `retry-errors-v2`。已有作答的 `memory-rounds-v1`、`three-rounds-v1` 以及更早固定组继续读取原流程和原答，旧排期及旧定性反馈不回写为新版事实。每日首次复习、新版 FSRS 采用和后台评价证据规则见 [学习流程规则](learning-flow-rules.md)；本文件不以 UI 自行推断排期。

判断和拼写上方各有一排进度标记，每个词的位置固定。判断时，实心圆是当前词，绿边是通过，红边是需要再次出现，灰边表示未轮到或达到判断次数上限。拼写时，当前词是三角形，实心圆是首答正确并已通过，空心圆是尚未通过。切换时轮廓在圆形和三角形之间快速过渡。旁白会读出具体状态。

每日学习与旧手动复习事实由本机 Node 服务保存到 `service/data/mini.sqlite`，包括词组、阶段时间、暂停恢复、自评初选和最终档位、拼写首答与订正、例句、独立写作材料、翻译原答、反馈、重点、明确偏好和帮助曝光。首次连接时导入旧 `DailyStudy/ledger.json`、`Review/current.json` 和 `Review/History/`，原文件及 `migration-backup/` 备份保留，成功后不再向旧学习账本写入。迁入的每日组也遵循同日续学、跨日重开的规则。旧手动复习记录独立于每日排期。

AI 备课、写作准备、反馈和学习顾问现在统一通过 HTTP 交给 Node 的持久任务，状态包括等待、进行、完成、失败、停止和中断。聊天页可查看公开进度、业务回执、停止和重试；停止不撤回已保存事实。任务与聊天保存在 `service/data/mini-ai.sqlite`，重开应用后仍可查看；服务重启不自动调用模型，未完成任务按真实保存结果恢复或等待主动重试。mini 单次模型轮次最长等待 6 分钟，超时后保留已有结果，可主动重试；这不是结果一定及时返回的保证。

从顶栏阶段菜单选择「AI 设置…」，或点击聊天页右上角的滑杆，即可打开同一个设置面板。依次点选模型和推理强度，点「应用」后用于新发起的备课、写作、反馈、顾问和英文对话任务。翻译点击「下一个」时会把当时的选择写入后台评价记录，后续修改设置不影响该条评价。默认选择为 `gpt-6.1-sol` / `xhigh`，已有本机偏好会保留。候选由运行时提供，所选模型不支持当前强度时，需点选其支持的强度再应用。

从顶栏阶段菜单选择「设置…」，或按 `⌘,`，可调整「词卡字号」。默认「中」沿用原字号，「小」比英文例句略大。设置立即应用到新词、复习判断和复习重学的英文主词，选择保存在本机。例句、释义和拼写输入沿用各自的字号。

同一面板的「学习样式」可选「丰富」或「简约」，选择即时生效并保存在本机。丰富保留蓝色高亮、彩色按钮和红绿反馈，拼写正确后可确认下一词。简约用加粗标出例句中的目标词，进度和反馈用中性色，操作按钮使用细边框。组内拼写正确后直接进入下一词，拼错时用原文字色显示答复并保留订正。首页沿用原有外观。学习页面的词卡、聊天、朗读和常用作答操作用图标表示，悬停可看中文提示。回忆时使用等宽的「Forgot」和「Got it」。组进度采用「1 · 2/20」格式，组间操作使用简短英文。小窗置顶并失去焦点时，词卡释义、例句译文、翻译输入和答案会原位模糊。英文、音标、拼写和翻译题目以及点评正文保持清晰，回到窗口或取消置顶即可看到原文。

学习计划页的底部始终提供当前范围的主要操作。今日安排可以直接切换正常学习、只复习或今天不学；创建临时安排后，底部可恢复长期安排。顾问页的「水平」用于设置英语水平，词书等级在计划的「词书」页选择。

在本组翻译页点「上一题」可以回看和修改之前的译文。「提交修改」后，首页「翻译点评」会更新这道题的点评。点「下一题」回到刚才的位置，各题已输入的文字分别保留。

在首页「今日记录」点「翻译点评」可回看当天各组提交的全部翻译，也可以切换日期。点开某题查看原题、自己的译文、AI 写出的优点和建议，以及参考译文。详情顶部显示当天的题号，点「上一题」「下一题」按当天列表顺序切换；首尾停在当天，点「全部译文」返回列表后可以选择其他日期。提交译文后或一组完成时也能进入。列表按提交时刻所在的本地日期归类，刚提交尚未确认的原答也可查看。点「下一题」后后台独立评价，已完成的点评会直接读取；失败的任务可逐题或一起重试，沿用已保存的原答。后台读取 Codex 账户时遇到超时或临时 RPC 内部错误，会自动再读取一次；这一步不重复启动模型生成。评分证据与复习排期仍保存在评价记录中。

列表和详情按翻译方向显示点评。英译中只有绿色「翻译正确」和红色「偏离原意」。意思译准时，点评简短确认读懂了什么；出现实质误解时，会指出具体哪层意思变了。中译英有绿色「表达地道」、黄色「可以润色」和红色「偏离原意」三档。

新提交的译文随点评一起获得档次。旧版英译中点评按新口径展示，现有证据不足的题目标为「待重新点评」。可在列表点「补评译文」，后台按当天的原题和原答补齐结论。补评保留原答及复习日期。

构建优先使用显式 `CODEX_BIN`、PATH 中的 `codex`，未配置时也查找 Codex App 默认安装位置的内置可执行文件；可用时无需额外安装另一份 CLI。移动运行时或仓库后需重新构建，Node 负责启动 App Server，Swift 不再直接启动 Codex 子进程。

学习顾问可查询真实学习历史与词义重点，调用当前任务允许的计划、重点和明确偏好接口，并查询音频或按明确请求生成、单条重生成；不能替用户答题、自评、过关或直接改排期。重点最多两个活跃项/词义，每组最多新增一个，暂缓和归档不恢复本组新增名额。明确稳定偏好最多 20 条，可在聊天中查看、更正和删除。当前每轮提示只携带最近 12 条会话消息，更多学习记录按需分页查询；聊天快照显示最近 200 条消息和 50 个任务，尚无完整聊天分页界面或自动长期摘要。

窗口由 AppKit 的 `NSPanel` 管理，界面由 SwiftUI 渲染，Swift Package Manager 构建。Node 按课程、反馈和顾问装载短 Skill，通过受限 MCP 读事实、提交材料及定性反馈。用户原答先保存，AI 自然语言不作为保存成功依据。当前词卡聊天在回复前保守保存帮助，不能把支持练习说成独立掌握。独立浏览词表可离线使用；已有材料的复习不依赖模型或外网，但需要本机学习服务。网页 D0 与学习原型尚未接入 mini 业务模块。

## 单卡默写与独立检验

完整词卡右下角的草稿图标打开独立的草稿拼写卡，位置紧邻音频更多选项。按回车或点“比对”时，输入立即显示绿色或红色，输入位置保持稳定。可直接订正，也可回车或点击“再拼一次”清空并聚焦输入框。点击“退出拼写”立即回到原词卡。作答、答案揭晓和关闭按操作顺序在后台保存，服务端确认作答后朗读当前词。快速重练或退出时，较早的朗读让位于当前练习。新版三个阶段均需完整词卡已展开时才能开启，复习重学使用相同入口。答后核对继续提供“记错了”和“下一个”。

底部读词和例句按钮保持固定图标与位置，音频加载和播放时保持同一外观。音频栏和两行音频提示从进入页面时预留固定空间，词卡曝光确认、音频加载和提示出现均不会挤动回忆按钮。停止播放收进更多菜单，更多图标直接点击展开并隐藏附加箭头。草稿拼写入口替代原先词卡下方展开的输入区域。

学习记录在后台写入，界面省略保存中、保存成功及手动重试控件。网络或服务临时故障时沿用原请求身份自动重试，首次发送后最多额外重试三次，耗尽后结束该次请求。复习版本冲突由现有身份与版本规则处理。播放授权期间的序列化检查与按钮外观分开，保持记忆按钮颜色稳定。草稿首次打开、再次拼写及输入框从不可用恢复后自动聚焦，提交和反馈时保留输入框位置。

新词和复习共用的整组拼写页在按下回车时立即给出反馈。拼对显示绿色和「下一词」，拼错显示红色并可继续订正，留空提交时横线标红。达到拼写次数上限时，显示正确拼写和「下一词」。输入行靠近进度点与底部音频栏之间的中央，释义在上，按钮和参考拼写在下。提交和订正时输入线保持原位，长释义可以滚动查看。服务端按操作顺序确认学习记录。复习出词时，后台记录词卡曝光期间也能点击「遗忘」「模糊」「清晰」。

输入框先响应按键，待提交的操作和草稿在后台写入本机文件。每笔操作沿用点击时的词、题次和时间，落盘后按顺序发给学习服务。迟到的回执只确认对应的操作，保留已经输入的下一词草稿。组内下一词沿用服务端已给出的顺序，新一轮的随机词序由服务端返回。

切词时，上一张词卡的关闭记录在后台按原词和离开时间确认。朗读已更新版本也能确认，较晚打开的卡片保持可见。切词后过期的自动朗读会取消，复习页不会因此弹出进度提示。

新词和复习重学的三阶段词卡在记录展示、授权朗读和接收后台回执时保持按钮原有颜色。确认推进后立即显示下一词，组末直接显示首轮拼写。后台按访问顺序保存，服务端核对每次访问并保存学习事实。同一次访问的重复点击只推进一次。

顶部组号靠左，逐词进度点对齐整个词卡的水平中心。空间不足时自动切换为进度条和计数。

参考拼写仅在错答反馈时显示，开始重新输入后立即收起，订正沿用正常拼写输入。输入重新变回旧错答也继续隐藏，下一次提交错误才显示新反馈。原生渲染测试核对答案区域出现、收起及重复输入，输入坐标和答后音频触发次数同步检查。

整组拼写每次保存首答或订正结果后，自动朗读一次当前单词，正确和错误均触发。播放沿用已缓存音频、全局静音和当前词卡约束，普通刷新和切到下一道未答题不会重复读词。答后听音保存实际播放记录，保留原答和当时的帮助条件。原生回调验证逐次触发与刷新去重，隔离 Swift/HTTP 播放链路核对错答和订正后的音频、回执及原始作答。

原生窗口交互检查覆盖焦点恢复、等待提交时的布局、正确与错误反馈以及重复拼写。隔离 HTTP 另外覆盖前三次临时失败后成功、重试耗尽停止，以及版本冲突立即交回调用者处理。五路原生业务流程与数据库重开检查通过。

草稿结果的原生交互检查覆盖错答红色、正确绿色、每个新结果触发一次读词以及普通刷新和再拼一次时的去重。音频接口核对提交前的自动播放约束、两种结果后的单词播放及原始答案保留。音频栏的原生布局测试核对加载前后、两行提示出现及刷新隐藏时回忆按钮的窗口坐标一致。更新后的下载目录 Dev 应用已实测出现在 Dock 并显示新图标，Cmd+Tab 可切回，关闭词卡后点击 Dock 图标可唤回，记忆曲线窗口也能按上次使用状态切回。

原生鼠标事件检查覆盖初见、核对、改判和后台保存期间的切词。Swift 经真实 HTTP 对照即时显示的下一次词卡访问和 SQLite 已确认结果。组末也核对拼写顺序。当前词卡访问确认后可授权朗读，迟到音频随切词取消。

独立拼写检验列表里的「建议检验时间」用于自行选词加练。每日任务的到期数在首页和记忆曲线窗口查看。开始检验后只显示中文题干，自动语音关闭。提交后保存不可覆盖的原始答案、分类与参考答案。服务端按实际曝光、帮助、间隔和交错情况判断证据资格，合格的独立成功/失败分别采用 FSRS-6 的 Good/Again。学习卡展示、听音、单卡练习与揭晓继续记录曝光，较早或受支持回答保留原始事实与分类。

记忆状态和待检验 due 位于 `mini.sqlite` 的调度快照，使用 `ts-fsrs@5.4.2`，目标保持率 0.90，学习/重学步骤 10 分钟。已介绍未检验词默认 10 分钟后提醒。旧排期历史保留，新计划按调度快照的真实到期选择候选。隔离原生入口和真实 HTTP 已通过，个人词库导入与连续自用继续核对。

## 词书与学习顺序

「学习计划」的「词书」将每套词表显示为一本封面，顶部提供统一的词汇等级与乱序／顺序选择。牛津 3000 只有一个封面，可筛选全部或 A1、A2、B1、B2；未分级词书显示全部范围。乱序在所选范围内稳定混排，选择全部时覆盖各等级；顺序按来源 rank，自定义词表则按输入顺序。选择词书或调整条件通过真实 API 保存，点底部固定的「开始学习」后创建新组。原 rank 和来源记录保留供追溯，活动词书提供下一组的目标候选。词库使用 `service/data/mini-vocabulary.sqlite` 的独立版本与幂等回执，切换词库和创建新组分别保存。

个人导入源放在 `service/data/vocabulary/sources/`，官方牛津 CEFR PDF 提供等级、词性与原行，ECDICT 提供中文和音标，保留固定 commit、SHA-256 与词义规范。当前解析为 3,313 条等级/词性原始记录，首次出现的来源 headword 3,003 个，大小写折叠后 2,981 个拼写。按首次等级分为 A1 902、A2 801、B1 699、B2 601，活动词数再按拼写和释义去重，个人导入回执已确认为修订号 1，完整活动词库为 3,003 个拼写/释义目标，大小写折叠拼写为 2,981 个。

AI 同时获得目标词的词表等级和用户的句子难度。已有 `english_level` 优先生效，未设置时采用 A1 造句指引，首轮即可按简单句准备。词条查询还可返回所导入的词性、释义、音标、等级与来源。词库和来源留在个人数据目录。个人完整 A1→B2 已导入启用。按字母选出的零作答组保留为导入验证历史，最终同级稳定乱序课程已创建首组并完成真实备课与音频缓存。

## 单词与例句语音

点小窗顶栏的扬声器可调节应用内朗读音量。单词、例句和起手句式共用这个设置。默认 100% 是原始音量，最高 200%，放大时会限制过高的峰值。拖动时正在播放的声音也会改变。点滑杆旁的扬声器能静音或恢复，应用会记住音量。调节在本机播放时生效，缓存的录音照常复用。

复习判断卡进入时自动读词，任一自评展开完整卡片后依次播放单词和例句。新词与复习重学的初见词卡可停留观看和练习，点击“记住了”立即进入下一词。句子回忆页自动播放该例句，单词回忆页自动播放该单词，完整词卡进入或展开后读词，结束半秒后读例句。点击单词或句子可重播该段，换词、手动播放、静音、隐藏、暂停或离页会终止剩余队列并丢弃迟到结果。同卡刷新和恢复继续使用原访问约束，每段分别保存实际开始回执。拼写和翻译保留主动请求英文提示。

例句中的目标词以强调色和加粗显示。备课可提供 `targetForms` 标注实际词形，支持时态、复数等变化，服务端校验标注在英文中的完整匹配。旧例句通过原词匹配及系统英语词形分析显示高亮。高亮元数据与例句保存，音频继续按实际英文文本复用。

当前词优先准备。选择学习新词后可在复习期间提前准备后续新词与例句音频；单独复习只用复习材料。进入新词而内容未齐时展示准备流程，音频失败后自动补缺，整轮备课齐备后再进入词卡。首页和学习计划只读预览，开始/继续学习后才预取组内单词和已有例句。开发阶段预览可真实生成、试听和单条重生成，复用开发服务的缓存、文件和播放器。资产持久保存，并与开发正常流程共享当前版本。预览试听跳过真实学习授权、帮助、开始回执与恢复 outbox。正常流程未确认的开始回执在预览中暂停保留，回正常流程按原身份与实际时间续发。预览/正常模式和词卡切换都会使旧访问结果失效。

首次生成从 `ryan`、`aiden`、`serena` 随机选择，缓存播放沿用已存音色。语音菜单可对单词或例句单条重生成，也可明确指定这三种音色；新版本完成后替换当前指针，失败继续保留旧录音。重生成只准备资产，需要时再播放。音标和词义提供软发音提示，实际正确性仍需试听。

正常流程由服务端在播放前核对当前阶段并保守记录 `potentialHelp`，授权回执与实际开始分开。播放器开始成功后，原生再保存实际开始时间，未确认请求持久重试。即使从浏览词表播放，只要内容包含当前答案，也关联当前学习目标。帮助不产生独立 Good，之后播放保留已保存首答的原条件。

音频任务、资产和回执保存在 `service/data/mini-audio.sqlite`，WAV 保存到 `service/data/audio/`，数据库使用小写 UUID 相对文件名。旧版本目前保留，清理与导出恢复仍待实现。生成和缓存查询只准备材料，用户学习事实由真实操作产生。

## 学习计划与当日续学

右上角菜单的「学习计划」提供长期、今日和词书三个范围。长期可选每周安排新词的日期、每日新词目标和每组数量，今日可少学、只复习或休息，次日本地日期恢复长期安排，不把未做内容变成双倍欠账。保存每组数量后，判断中的复习组按实际进度增减。已展示和已作答的词保留进度，缩组放回多余的未做词。已经开始重学或拼写时，下一组采用新数量。今日记录带明确日期和 IANA 时区，跨日未保存的旧操作不会误改今天。

以下词数容量规则仅供旧组兼容；新版按每日最终完成目标和组量组织。旧组本次容量优先于今日和长期容量；今日休息、只复习仍限制可做阶段。词数按本次实际服务的不同词目计算，同一词的订正、后续拼写和写作不重复扣量。达到词数或新词上限时，在进入下一个尚未服务的目标前暂停。有效作答先保存，输入、首答、轮次和原组保持不变。「结束本次」只结束会话并暂停，继续后使用新预算，不表示任务已完成；反复点继续不会重置正在使用的预算。

首页分设复习和新词两个按钮。当天返回首页、关窗口或退出应用后可从相应入口接着做。到期复习每天可做，休息日可以主动加练一组新词。次日先按实际排期复习，随后按当天计划开新组。上一天的部分拼写、译文与点评仍属于原记录，完成数和到期日期只随真实完成事件更新。

最近一次实际学习距离当前学习日满 3 天时，首页显示间隔天数。真实自评、记词、拼写、翻译和实际练习都计入学习活动。可从首页底部进入到期复习或新词学习，组量按当天计划安排。

## 重置本机学习数据

把 `scripts/reset-mini.command` 放在应用旁（或从仓库的 `scripts/` 运行）。双击默认针对**正式版**，确认窗默认取消。只有明确选「退出并清空」才会退出该版本、停止并核实其本地服务、删除数据。重置 Dev 必须从终端显式传 `--dev`；两个版本互不清理。不支持指定任意数据目录。

- 清除：学习账本、句式练习、计划、自评和复习排期、AI 教学和评价任务、聊天及已保存的评分证据、草稿、旧版记录及迁移备份、自动生成的例句、音频数据库与 WAV、该版本的工作目录、日志和缓存。

## 聊天原文与上下文

本机的 `service/data/mini-ai.sqlite` 保存完整的用户消息和助手公开回复，不是只存摘要。每条有 `id`、`conversationId`、`role`、`text`、`createdAt`、`jobId`；任务另存模型、推理强度、运行状态和业务回执。学习顾问、单词义项、英文场景分开。原生界面全局快照取最近 200 条消息与 50 个任务，不代表清除了更早的数据。每次模型通常只读同会话最多 12 条，并按任务另取学习事实。评分任务用到的答后讨论可能另存于学习证据中，整版重置会一并清掉。

AI 库与学习库各自事务提交，任务库先保存固定工具命令，再由学习库提交业务事实；重启时按业务回执补认任务结果，部分发布内容保留、只补缺项。音频库同样先保存固定播放授权命令，再通过学习业务回执恢复对账。各库和文件使用可恢复协调。手动备份先停止服务并保留整个 `service/data/` 的四个 mini 业务库、音频、词库来源和相关文件。应用内导出恢复与统一清理本轮暂缓。

Swift 提交共享命令并读取服务端快照；请求身份、预期版本与首次操作时间一同保存，重试沿用原请求。服务端校验阶段与旧记录的一致性，事务保存学习事实、事件和幂等回执；版本冲突返回 `409`。若仅追加后台材料，或追加模型评价事件及其严格关联的新版调度变化链，而原有学习、帮助、计划、会话、评价输入及其他调度事实完全一致，客户端对仍匹配当前 visit/task 的作答或确认动作使用新请求身份及原操作时间安全重试一次。已有评价事件不能被改写，变化链必须从旧卡精确生成当前卡；其他冲突刷新进度并保留输入。暂未确认保存时保留待发送请求和输入，不显示为已保存，也不退回旧账本继续写入。

退出窗口或 mini 应用不会关闭共享的本地服务。可在仓库根目录正常停止开发版服务：

```sh
node scripts/mini-service.mjs --dev --stop
```

正式版去掉 `--dev`。下一次打开对应应用会重新启动服务。不要通过删除运行中的数据库、锁或服务目录停止进程。
