# 记忆曲线

从 mini 的「记忆曲线…」打开独立大窗口。左侧用散点、每日已排期数量和词汇记录展示全局，右侧显示一个词义的学习轨迹。窗口可缩放或全屏，关掉后可从原入口再次打开。

## 在几千个词中找到一个词

「词汇记录」每页显示 20 条。列表上方显示页码和翻页按钮。搜索框按英文拼写或中文释义查找，状态筛选作用于全部词汇记录，更改搜索或筛选后从第一页开始。散点展示筛选结果里符合当前日期和所选能力维度的词。翻页时，散点、排期负荷和顶部统计维持各自的统计范围，右侧保留正在查看的词。

点击散点可定位到对应的列表页，点击词条可查看详情。同一拼写的不同词义以 `senseId` 区分。列表保留未到当前日期范围的词，以及已有学习记录但仍在积累证据的词。尚未学习的词书条目不会增加这里的计数。

## 如何读图

- **词汇分布**的横轴是下次复习日期，纵轴是 FSRS 对当前回忆率的估计。可以在词义、拼写两个维度间切换，使用日期预设、缩放和平移观察不同范围。
- **待复习**与首页共用同一份每日队列，包含当天已开始、还未结束的复习组。副标题单列原定日期早于今天的积压。缩放时间范围不会改变这个总数。
- **复习负荷**按原定日期汇总每词的下一次排期，覆盖视窗触及的完整当地日期。积压保留在原定日期的柱上。只有排期、尚缺词义或拼写测量的词也计入负荷，缺少测量的维度暂不画散点。
- **累计学完**与首页沿用同一套完成记录。详情的“最近复习”采用实际复习或独立检验时间，同组判断与拼写合计一次。后台翻译评价可以更新能力估计，复习次数只随学习者的操作增加。
- **单词详情**用已保存的证据重建历史。向未来延伸的曲线假设期间没有额外复习。某一维度缺少证据时保留未知。长历史会按接口上限取样，缩小日期范围可查看更多细节。

## 数据与验证

窗口通过 mini 的本机鉴权读取两个接口。`POST /api/mini/memory/overview` 返回摘要、词汇和日期负荷，`POST /api/mini/memory/detail` 按词义和日期范围返回曲线与事件。原生客户端在已读的词汇结果上分页。浏览与翻页不写学习记录，也不触发 AI 或音频任务。[查询契约](../../packages/contracts/src/mini-memory.ts) · [服务端投影](../../apps/server/src/mini-memory.ts) · [原生窗口](../../apps/macos/Sources/LingoWeaveMini/mini-memory-view.swift)

改动列表后，用超过一页的数据核对页边界、跨页搜索和散点选词，再比较翻页前后的统计。改动投影后，核对查询前后的学习快照、版本和复习排期。原生与 HTTP 集成通过 `pnpm test:mini` 运行。[原生测试](../../apps/macos/Tests/LingoWeaveMiniTests/mini-memory-client-tests.swift) · [服务端测试](../../apps/server/src/mini-memory.test.ts) · [排期场景与验证资料](../research/mini-scheduling-scenarios-2026-11-17.md)

2026 年 11 月 20 日用 3,003 个合成词义验证了 151 页的顺序和覆盖范围。隔离原生窗口中，点击末词的散点后，列表定位到只有 3 条记录的末页，右侧显示该词详情。按英文或中文从首页搜索都能找到该词，清空搜索后恢复首页 20 条。

2026 年 11 月 21 日重新执行了 19 类表现的 90 天隔离模拟，复习包含客户端实际发送的英文题面展示命令。以学完当天为第 0 天，持续清晰且独立拼写正确的样词在第 1、3、14、60 天复习。持续模糊的样词在第 1、2、5、12、24、42、67 天复习。持续遗忘并且拼写三轮首答均错的样词每天到期。另用连续三天学习、次日首复习、真实求助和当天不同打开时间的回归，核对首页与曲线的待复习数。每日综合复习从排定日期的当地日初可做，能力详情保留模型的精确建议时间。[可复跑的场景](../../scripts/test-mini-scheduling-scenarios.mjs)
