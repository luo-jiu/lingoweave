# 数据总览

从 macOS 菜单栏的「窗口 → 数据总览…」打开，快捷键是 `⌘3`。也可以右键菜单栏上的语织图标进入。总览和记忆曲线一样使用独立大窗口，复用窗口的大小和位置。右上角可刷新并查看更新时间。「数据位置」显示当前服务实际使用的资料目录，可复制或在 Finder 打开。

## 统计口径

- 学习统计覆盖当前应用实例。完成词数按词义去重，复习词次在同一组内按词义去重，已提交的独立检验也计入。学习天数按实际练习发生的日期计。翻译首答和底层操作事件分别显示。
- AI 区分会话、消息和翻译评价。评价按任务状态计数，首答和提交过的改译各自有评价身份。
- 音频区分词音和例句、当前与历史版本、任务状态及文件异常。缺失文件有资产记录，未登记文件存在于音频目录中，检查只做匹配，保留文件原样。
- 存储条按文件逻辑字节数汇总应用的数据目录和服务日志。数据库的 WAL 和 SHM 文件计入对应类别。模型权重与 SDK 仍位于独立目录。正式版和开发版各自读取所属服务。

窗口通过本机鉴权的 `GET /api/mini/data-overview` 读取数量、大小、数据路径和统计时间。打开或刷新仅查询现有数据，无需启动 AI 或生成语音。[共享契约](../../packages/contracts/src/mini-data-overview.ts) · [服务端统计](../../apps/server/src/mini-data-overview.ts) · [原生界面](../../apps/macos/Sources/LingoWeaveMini/mini-data-overview-view.swift)

## 更改存储位置的后续设计

入口适合放在数据位置一栏。首次选择空目录时，把当前正式版或开发版的业务数据整体迁移，包含各库、词库来源、生成音频、原文资料和客户端待确认记录。两个版本各自保存路径。固定的应用支持目录保存路径指针、本机服务身份和启动信息。

迁移先暂停写入并正常停止服务。把原位置的数据复制到目标卷的临时目录，检查数据库完整性、版本、音频引用和文件校验值，再提交新的路径指针并用数据身份验证启动。流程应能在断电、空间不足、目标卷断开或启动失败后继续或回到原路径。外置卷未挂载时，提示恢复访问，避免另外创建一套空记录。目标目录已有数据时，应先辨认数据身份，让用户明确选用哪一套。确认新位置可用后，原副本的移除单独处理。当前窗口提供查看与定位，迁移作为后续独立功能实施。
