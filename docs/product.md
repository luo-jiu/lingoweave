# LingoWeave 产品约定

LingoWeave · 语织当前服务用户自己的英语学习，以小窗支持工作间隙随手开始、隐藏与恢复，学习效果和使用体验优先。它帮助基础薄弱的学习者逐步提高英语阅读和书面表达能力。它从词汇和短句起步，未来扩展到词根、常用表达与个人阅读材料，不围绕考试大纲或自由口语对话组织首版功能。

本文记录产品与教学设计；网页当前实现 D0 材料准备、保存与 Agent 接入，并增加独立的[学习工作区交互原型](study-workspace-prototype.md)。原型使用演示词组，复习操作不写入真实学习数据。macOS mini 已将学习事实与业务命令统一到 Node 服务，实现三层计划与缺席恢复，并新增任务化 AI、历史工具、重点、有限偏好、独立写作和定性反馈；四类文字任务已分别通过真实模型与工具保存验证。本轮已实现单词/例句音频资产、播放和单条重生成，真实离线生成和音频 HTTP 流程已验证，工程检查和真实顾问音频工具验证已通过，复习判断预览已核对真实生成及播放，其他阶段界面与主观听感仍待验收，实际范围见 [macOS 悬浮词卡](macos-mini.md)。本轮 mini 已补单卡支持练习、独立拼写检验及 FSRS、词库计划、快捷键和应用封装，工程、隔离窗口流程、个人乱序首组与真实备课已验证，快捷键按键动作仍待人工确认。网页原型与其余完整教学测量继续按分项推进。实施范围见 [Demo 计划](demo-plan.md)，既有真实 Agent 备课结果见 [D0 验收](d0-acceptance.md)，通信和模块职责见 [架构](architecture.md)。

2026 年 11 月 17 日确认新的学习流程，唯一详细规范见 [学习流程与评价规则](learning-flow-rules.md)。窗口交错、三轮拼写上限、每日新词完成目标与后台调度评价已接入新建任务；既有旧组保留原规则。以下目标流程按这次确认更新；当前实现与历史证据仍见 [mini 学习、AI 与语音方案](mini-ai-learning-plan.md)和 [mini 验收](macos-mini.md)。此前“写作反馈一律不参与排期”是旧实现边界，新方案允许经服务端校验采用的结构化评价影响后续复习，AI 不直接改写学习事实或到期时间。

完整背景和来源调研见 [立项构思与落地评估](research/product-exploration.md)；间隔学习、动态负荷与算法实验见 [学习算法与 AI 教学流程研究](research/learning-scheduler.md)。这些资料统一保存在项目内，当前产品约定以本文及关联专题规则为准。

## 核心分工

算法决定学什么、复习什么和本次负荷。AI 可以查询完整学习历史，决定如何解释、准备材料、出题和反馈。程序保存实际发生的学习，并执行阶段门槛、预算和评价采用规则。

用户主要在 mini 操作，网页保留工作区与扩展入口；两端后续共用同一服务端事实。AI 在后台通过 Codex 运行时与平台交互，不要求用户来回转述。AI 可提前备课、在阶段后分析表现；复习、新词自主背诵与总拼写循环由平台执行，不逐词调用模型。

理解、拼写和运用需要分别观察。新词完成记忆后进入拼写，拼写阶段正常结束或达到三轮首答失败上限后都进入翻译；失败事实参与后续复习评价。会拼不代表理解、长期记住或能自由写作，自评“记住了”也不等于独立测量成功。

## 一次学习

首页分别提供到期复习与新词学习。复习每天可做，新词按学习日、每日目标和每组数量安排，休息日可主动加练一组。先完成全部到期和积压复习，再开启或继续新词；可以暂停，未处理的复习保留。例：每日新词目标 50、每组 20，按 20、20、10 完成记忆、拼写和翻译；这些数字只是流程示例，不改变用户当前设置。学习可随时暂停，当天从相应入口接续。

### 复习

到期词可以分组处理，先回忆词义，再做该组拼写。词义卡片最初只有英文；选择「遗忘」「模糊」「清晰」后揭晓释义。清晰退出判断队列，模糊与遗忘在下一轮重新遮挡考察。每轮第一次遇到该词才算一次首见；三轮仍未清晰的词进入与新词相同的三阶段重学，完成后参加拼写，复习不增加翻译。重学仍属于复习，不计入新词完成数。

遗忘表示想不起来或核心意思错误；模糊表示能够想起核心意思但费力或不确定；清晰表示有把握地想起。工作间隙可能被打断，停留时长不直接决定评价。揭晓后可以修正或撤销自评，但保留原始选择与揭晓事实。

任一自评完成后，卡片才显示可选单卡默写图标。用户主动切换为中文提示输入并比对答案，只练当前词；取消自评会收起练习。该结果不计入掌握、整批轮次或已通过数量，不替代判断与整批拼写。

判断通过或完成三阶段重学后，进入下述统一拼写流程。拼写结束即完成该词本次复习，三轮失败也保留本次完成与失败事实并安排更近复习。自评、支持练习、独立证据与调度评价分别保存，不把纠正后的正确机械转换成独立 Good。

### 新词观看与自评

新词默认独立经过完整词卡、仅英文例句、仅英文单词三个阶段。完整词卡另有「已认识」，可将熟悉的词直接送入本组待拼写队列。AI 分别读取自报、拼写首答、订正和译文；该词确认翻译后才计入已学。阶段 0 点击「记住了」直接切下一词，选择在后台保存。阶段 1/2 先选择想起或想不起，再展开完整词卡，读词后停半秒读例句，停留核对。想起立即多亮一颗绿点，想不起立即清零并保留学习画面。点「记错了」立即切下一词，原词退回阶段 0。其余情况点「下一个」按最终选择确认，并处理出窗、补位。

默认窗口同时保留 5 个词，处理另外至少 3 个不同词后允许再次出现，按公平交错顺序调度。不会或记错经下一词确认后退回完整词卡，保留在窗口；三个阶段全过并确认，或新词选择「已认识」后腾出位置，下一张优先补入新词。达到本组需要的通过数量时，先暂停窗口并进入拼写，不再补词。此流程也用于复习三轮未清晰后的重学，但复习腾位只补待重学复习词；普通复习判断不改为一开始就走三阶段。具体调度与核对例子见 [学习流程与评价规则](learning-flow-rules.md)。

每词三个点显示独立阶段的最新结果，随当前初选和改判立即更新，退出后恢复同一核对状态与绿点。初见可展开草稿区，原始输入、比对、初选、揭晓、改判和帮助由服务端保存。三阶段词卡移除通用「撤销」及常驻「已按学习规则保存」，使用核对态的「记错了／下一个」；真实保存失败仍提示并保留当前卡。音频未结束也可前进并取消旧播放。组满时剩余最多 4 个窗口词保留原进度，当天的下一组继续；它们不参加本组拼写，也不计入完成数。材料池按剩余新词目标加窗口大小预备，准备、入窗、记忆通过和最终完成是不同事实。

### 整组总拼写

复习与新词使用相同规则：首轮覆盖本组，后续每轮仅包含上一轮首答错误的词。某轮首答正确后，该词立即退出本组拼写，不因更早的错误再次出现。每词最多三轮首答，订正次数单独保存且不增加失败轮数。

首答正确后完整单词显示绿色，再次回车继续。前两轮首答错误须订正，订正成功同样停留等待确认；第三轮首答仍错，展示正确答案与错误位置，允许继续，不强迫再次订正成功。空白时按回车表示完全想不起，按错答处理并显示正确拼写。新词拼写结束后进入翻译，复习拼写结束后完成本次复习；失败影响后续复习安排，不撤销已发生的学习。

暂停恢复未答位置、订正草稿或绿色确认状态，不重复首答和结算。旧组保存原规则版本和事件；新流程迁移需显式保存切换点，不能用新规则重放旧记录并制造新的成功、失败或完成事实。

### AI 分析和句子练习

AI 可读取每词观看、自评、阶段退回、各轮拼写首答、订正、帮助和实际时间。摘要关联原始记录，备课、反馈与顾问任务可按需回查；分析失败不妨碍保存或继续自助流程。

拼写阶段结束后组织简单英译中、带框架或词库支持的中译英，逐步减少支持。理解题与输出题可以采用不同难度，不能要求基础薄弱者一开始就自由写作。用户修改难度时保留当前答案，调整未开始的内容。

翻译没有必须订正才过关的门槛。用户可停留查看更好的表达或与 AI 讨论；点击下一词先可靠保存原答、完成事实与评价任务，随后直接进入下一道翻译。后台可以逐题处理或合并少量任务，但半组暂停也不能漏掉已提交题目。评分状态只在首页显示处理中或待重试，翻译页面不显示评分进度，也不等待上一题完成评价。

教学反馈说明合理之处、改进项和重点；后台调度评价则结合该词学习过程与原译文，提供结构化结论和依据，由程序按统一规则采用并安排复习。目标词错误与其他语法、表达风格分别判断。原答、帮助与讨论时间截断、模型和规则版本、结果理由、采用结果及排期前后值均可追溯，保留重试与采用回执，不保存模型隐式推理；人工申诉与修订版入口尚未实现。讨论后的答案不能覆盖原始首答。

备课、写作反馈、调度评价与学习顾问按任务提供 Skill 和受限工具，共用运行时；普通回复不是业务保存回执，AI 不能直接指定新的掌握或 due。新增表达也不能自动扩成另一组学习任务。评价适配、证据保存与持久任务已接入，完整边界见 [学习流程与评价规则](learning-flow-rules.md)。

mini 已实现 Node 备课、写作准备、定性反馈、顾问任务，以及独立的后台调度评价。新建组的写作题采用独立材料并换句子，缺材料等待准备；已保存原答与题目不被重试覆盖。重点以词义身份关联，首版每词义最多两个活跃重点、每组最多新增一个，暂缓和归档不重置新增预算；已有常用重点优先复练。明确偏好最多 20 条，AI 保存须引用真实用户消息，可查询、更正和删除；当前没有自动长期摘要或向量记忆。

当前词卡聊天先保存保守帮助条件，后来的回复不能改写先前首答，带帮助首答不用于较长练习间隔。既有轮次保存练习与帮助，显式独立检验的合格首答采用 FSRS，单卡支持练习与定性反馈保留各自教学用途。开发阶段预览的学习、聊天与文字 AI 示例仅在内存。语音可复用开发服务实际生成、播放和重生成，音频资产持久保存并共享缓存及当前版本。预览试听直接使用播放器，学习帮助与开始回执由正常流程保存。

### 显示设置

页头显示设置提供主题与可持久化的简约模式。简约模式隐藏辅助引导文字，包括整段学习标题与说明、装饰性小标题和聊天介绍；真实错误、暂停、轮次、进度、演示未保存和 AI 未连接等必要提示保留。关闭后恢复引导文字，切换不重置自评、练习或输入草稿。普通控件保留紧凑的键盘焦点；组合输入与选择框仅由外壳显示一圈焦点。

## 怎样保持动态

mini 的显式独立拼写检验已接入 FSRS-6、`ts-fsrs@5.4.2`，目标保持率 0.90，关闭随机 fuzz，学习/重学步骤为 10 分钟。原始首答须先经曝光、帮助和真实间隔分类，合格独立成功/失败分别采用 Good/Again。参数作为固定基线保存，工程和隔离窗口流程已通过，真实连续使用继续核对。

FSRS 维护难度、稳定性，并按真实经过时间估计当前可提取性。没有新回答时只计算当前估计，不每天写入失败或更改模型状态。以前熟练的词也会随时间再次到期；停学后使用真实间隔继续更新。

新方案要求新词最终完成后的下一个本地自然日必复习，之后依据实际表现和历史计算间隔。首次次日安排是产品规则，不冒充有效测量或伪造记忆概率；三个记忆阶段、拼写、翻译评价保留各自证据来源。综合评价适配、首次次日安排与小范围错峰已有实现和隔离验证；具体证据资格与有界保守规则见流程规则，长期效果仍需实际使用验证。

新词日目标不是欠账；到期复习会积压，不能因缺席而清空或改期掩盖。完成一词指三个记忆阶段已过、拼写阶段已结束、译文已提交并确认进入下一词，不依赖 AI 评价返回。仅观看、入窗或记忆通过不计入新词完成数。

| 情况                       | 预期行为                                                          |
| -------------------------- | ----------------------------------------------------------------- |
| 今天完成 50 个新词         | 明天至少有这 50 个首次复习，另加历史到期量；不能承诺没有峰值      |
| 某词没有被安排或没有作答   | 保留真实 due 与历史，不记失败、不假装完成                         |
| 三周后恢复                 | 保留现场，先处理到期复习，再继续未完成新词                        |
| 组满而窗口仍有未通过词     | 保存最多 4 个尾部词与各自阶段，当天可继续，跨日再遇从完整词卡开始 |
| 用户正在输入时需要暂停     | 保留草稿与有效操作，不突然换题                                    |
| 复习需求长期大于可投入时间 | 展示预计负荷、建议减少新词；积压未清时不开放新词                  |
| 翻译已前进但评价尚未返回   | 完成数已保存，首页显示后台状态，旧结果不覆盖后来的真实复习        |

mini 长期与今日计划保存每日新词完成目标及组大小，适合零碎时间学习；旧组仍保留按首次服务词目和容量计算的兼容行为。今日覆盖绑定当地日期和 IANA 时区，首页与计划窗口只读预览，业务动作在安全边界暂停。现有 `planning.activeDayId`、保留组、只复习另组与原答恢复可作为迁移基础；新旧字段分别解释，旧词数上限不会截断新版复习和完成计数。

计划保留长期设置、今日少学/休息和本次暂停。修改未开始部分时不丢弃窗口尾部、未完成拼写或译文，不因开关应用、后台备课和 AI 返回增加学习量。未完成新词次日重新参加选词，当天到期复习结束后，再遇到这些词从完整词卡开始。切词书也不复制或重置原义项的历史。

到期顺序综合实际 due、预计遗忘与等待时间，避免某些词长期得不到服务。错峰只在算法允许的小范围内优先选择负荷较低日期；次日必复习和高风险词不能为了图表平滑而任意推远。不能仅用每日展示上限把积压隐藏成已处理。具体评分采用、优先级和公平性随规则版本验证，不把旧的固定“五个位置轮转”当作已证实最优值。

### 词库与用户水平

个人牛津 3000 学习计划按词书组织，每套词表显示为一个封面。顶部统一选择全部或书内等级，并可选择稳定乱序或来源顺序；未分级词书使用全部范围。完整范围的乱序覆盖各等级，原始排序保留供追溯。官方词表提供 CEFR、词性和原词条，中文释义与音标采用固定 ECDICT 来源及导入词义规范。活动词库决定后续新组的候选，已有任务继续保存原目标和作答。词表等级描述目标词，用户英语水平控制例句长度、语法和配词，首次可直接按默认 A1 指引造句。个人数据已导入并启用完整 A1→B2，活动目标为 3,003 个拼写/释义项，大小写折叠拼写为 2,981 个。首组由真实计划选出 so、where、note、clean、cool，已完成真实 A1 句子备课及单词和例句音频缓存。

应用包已补 Node 22.22.0、服务依赖与相对启动路径，全局快捷键默认 Control+Option+Space，可切换备用组合或关闭。搬移服务和隔离词卡/写作/检验流程已验证，快捷键实机按键仍待确认，应用内导出、恢复和清理本轮暂缓。

## 什么算有效证据

| 情况                               | 保存与评价                                            |
| ---------------------------------- | ----------------------------------------------------- |
| 明确目标在无答案帮助时正确回忆     | 保存独立成功，符合规则时采用 Good                     |
| 有效测验中无法回忆，随后请求揭晓   | 保留首次失败；后续照写不覆盖 Again                    |
| 教学阶段主动提供答案或词库         | 保存支持下练习，不仅因帮助而判 Again，也不记独立 Good |
| 翻译使用正确同义词，未要求指定用词 | 翻译可成功；未测到的目标词不更新                      |
| 目标词正确但其他语法有错           | 分别反馈，仅更新有明确证据的能力                      |
| 题干或批改不确定                   | 待核对，不惩罚或提升记忆状态                          |
| 尚未打开、未作答或离开             | 未测，不更新                                          |

帮助需要在发生时记账，包括点词揭晓和聊天中展示当前答案。单卡默写已保存额外原始输入、比对与答案揭晓，并作为支持练习和最近曝光纳入后续测量；单卡正确不能产生独立 Good。不能仅靠阶段小结回忆是否给过提示。评分修正保留版本，按原始作答时间重算，迟到结果不能覆盖新题或重复结算。

## 资料与后续扩展

词表决定范围和优先级，词典提供义项、音标和词形。首批计划从 NGSL 1.2 或已选核心范围整理 30～50 个核对过的词义；牛津核心词表可作为分阶段参照，不把公开浏览等同于整部词典的分发授权。

NGSL、Wiktionary / Kaikki 与 ECDICT 是候选来源，采用前检查具体文件、字段、质量和许可，保留版本与署名。例句正文保持简洁，真实引用在译文前显示「书名」，自拟例句省略来源标签。原文候选从本地校验文本检索，AI 结合当前义项和等级选句并翻译，提交时核对引用身份、英文原句和出处。缺少合适候选时使用自拟例句。缺失音标保留为待补数据。词库未收录的输入显示待查，合法词形先关联词目，不能一律标红。

语音首版已实现单词发音和英语例句朗读，共用本地 TTS，分别索引与缓存。明确开始每日组后，在复习期间后台准备后续新词例句和音频，当前复习可继续。进入新词若内容未齐，显示选词、例句、单词音频和例句音频四步的实际数量及进度，齐备后进入看词。新增准备流程已通过受控 HTTP 与 360 × 300 点实际进度/完成跳转检查，失败滚动与其他阶段完整界面仍待核对。复习判断卡进入时读词，选择任一自评展开后再次按单词、例句顺序连读。新词初见与后两轮主动展开完整卡片也顺序连读。后两轮收起时只显示当前轮内容。点击单词或句子可重播对应声音，手动播放、换词、静音、隐藏和暂停会终止原播放队列。拼写首答和订正出结果后自动读一次单词，正确与错误均触发。拼写与翻译保留手动提示操作。主动请求答案音频时，服务端先授权并保守保存帮助，播放器实际开始后再保存开始时间；授权和已入队都不等于实际播放或已生成。即使从浏览词表请求，只要音频含当前答案也记录帮助，提交后播放不改写首答。新词候选池内的例句和两类音频全部就绪后才开放词卡。音频生成失败先自动重试，连续失败可手动补缺。资产、缓存与播放规则见 [mini 学习、AI 与语音方案](mini-ai-learning-plan.md#本地音频生成与复用)。声音克隆和确定性的音素/拼音控制仍未接入。

未来材料 Skill 可从用户提供的 PDF、文章或句子整理目标与计划。平台需要提供文件登记、解析、来源定位、计划预览和受控启用。重复材料复用原词义历史，词根与句式需要各自的测量规则，不能直接套作单词拼写卡或读完即记 Good。

## 科学依据与待验证参数

间隔练习、主动提取和纠正反馈具有研究支持；接触次数值得记录，但没有“每个词见十次就长期掌握”的统一门槛。理解与产出能力不同，母语释义可帮助初学者。具体组大小、交错顺序、补测次数与 AI 教学流程仍是需要跨日使用验证的设计。
