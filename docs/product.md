# LingoWeave 产品约定

LingoWeave · 语织帮助基础薄弱的学习者逐步提高英语阅读和书面表达能力。它从词汇和短句起步，未来扩展到词根、常用表达与个人阅读材料，不围绕考试大纲或自由口语对话组织首版功能。

本文记录产品与教学设计；当前实现 D0 材料准备、保存与 Agent 接入，完整背词与复习阶段仍待开发。实施范围见 [Demo 计划](demo-plan.md)，实际结果见 [D0 验收](d0-acceptance.md)，通信和模块职责见 [架构](architecture.md)。

完整背景和来源调研见 [立项构思与落地评估](research/product-exploration.md)；间隔学习、动态负荷与算法实验见 [学习算法与 AI 教学流程研究](research/learning-scheduler.md)。这些资料统一保存在项目内，当前产品约定以本文及关联专题规则为准。

## 核心分工

算法决定学什么、复习什么和本次负荷。AI 可以查询完整学习历史，决定如何解释、准备材料、出题和反馈。程序保存实际发生的学习，并执行阶段门槛、预算和评价采用规则。

用户全程在网页操作。AI 在后台通过 Codex 运行时与平台交互，不要求用户来回转述。AI 可提前备课、在阶段后分析表现；新词自主背诵与总拼写循环由平台执行，不逐词调用模型。

理解、拼写和运用需要分别观察。拼写是首版新词进入句子练习的门槛，但会拼不代表理解、长期记住或能自由写作。自评“记住了”只表示准备接受检查。

## 一次学习

先确定本次时间或词数容量，完成预算内到期复习，再由用户选择是否开始新词。默认五词一组，可减少；五词是教学组织方式，不是每天必须完成的最低数量。

### 复习

先给清楚且不泄露答案的题目，保存第一次回答，再给反馈。拼写复习可使用中文义项、词性和必要中文语境。有效测验中独立回忆成功记 Good，不能独立完成记 Again，间隔由 FSRS 按真实时间与历史计算。

错误后可展示答案并提供一次订正机会。订正不覆盖首答；之后默认最多安排一次有间隔的额外补测，并计入本次预算。补测仍不会可以结束，不要求无限循环到全对。题目含混、合理同义表达或批改争议先核对，不直接判遗忘。

### 新词观看与自评

先准备好本组材料：一个当前常用义、词性、可用音标、简洁中文释义和简单中英例句。用户观看、隐藏内容、在心中回忆并标记是否记住。可交错回看已出现的词；观看顺序与轮数是可调整的交互设计。

这个阶段没有拼写、填空、翻译输入，也没有 AI 实时提问或加测。全组目标均自评记住后，用户才进入总拼写。缺少必备材料在准备阶段解决，不能逐张卡片等待 Agent。

### 整组总拼写

每轮覆盖全组，给出明确中文提示并隐藏英文答案与相关历史答案。每题先保存原始提交，整轮结束后集中反馈。未通过的词回到观看和自评，再开始下一轮整组总拼写；回看阶段没有订正输入。

当前轮全组均取得合格的无答案提示成功，才进入正式句子练习。刚揭晓后立即照写不能过关，要隐藏答案并通过交错或稍后继续形成真实回忆机会。具体短期间隔与分类规则在实现前固定版本，不宣称存在一个适合所有人的最佳分钟数。

一轮可以跨会话完成，暂停后恢复未答位置；开始新轮才重测整组。所有旧轮次与首答都保留。全组第三轮过关，不代表每个词都到第三轮才会，必须保存每词首次成功轮次。

有效词级证据及时保存和更新调度，不等整组通过。每轮短期正确也不能机械累加独立 Good；先按统一测量规则检查时间、帮助与题目条件。用户随时可暂停，预算耗尽时提醒暂停，主动继续才扩充预算。

### AI 分析和句子练习

背词结束或暂停后，AI 读取每词观看、自评、回看、原始拼写错误、首次成功轮次、帮助和时间。摘要关联原始记录，两个角色均可回查。暂停分析不能绕过拼写门槛；分析失败不妨碍保存或继续自助背词。

通过后再组织简单英译中、带框架或词库支持的中译英，逐步减少支持。理解题与输出题可以采用不同难度，不能要求基础薄弱者一开始就自由写作。用户修改难度时保留当前答案，调整未开始的内容。

出题角色准备课程和处理深入分析，陪伴角色解释、提示、回应追问并生成小结。普通回复在聊天区展示，题目、提示、评价和小结通过结构化工具提交。语法反馈与目标词表现分别记录，出现一个新短语不能自动扩成另一组学习任务。

## 怎样保持动态

记忆模型计划锁定 FSRS-6、`ts-fsrs@5.4.2`，目标保持率从 0.90 起步。版本和参数属于可复现基线，不是已经验证的个人最优设置。依赖尚未接入；后续升级模型须独立验收。

FSRS 维护难度、稳定性，并按真实经过时间估计当前可提取性。没有新回答时只计算当前估计，不每天写入失败或更改模型状态。以前熟练的词也会随时间再次到期；停学后使用真实间隔继续更新。

未检验的新词不伪造记忆概率。已介绍待检验的词可用独立的 `next_probe_at` 提醒继续原教学包，但不能绕过全组自评条件，或在看词途中插入拼写。

每日计划是当下候选的视图，不是一份必须补完的欠单：

| 情况                           | 预期行为                                   |
| ------------------------------ | ------------------------------------------ |
| 今天学 100 个、明天只愿学 1 个 | 按明天容量选择 1 个，只更新实际发生的学习  |
| 某词没有被安排或没有作答       | 保留真实 due 与历史，不记失败、不假装完成  |
| 三周后恢复                     | 保留现场，按当前时间重新安排尚未开始部分   |
| 五词组只完成一个目标           | 保存进度，下次继续，不强迫从头重做         |
| 用户正在输入时预算用尽         | 保留草稿，提示暂停，不突然换题             |
| 复习需求长期大于容量           | 减少新增建议并显示负荷，不改日期来清空积压 |

词数容量按词目去重，理解和拼写仍保留各自目标；题量、时间和补救次数同时受限。到期复习优先，默认每第 5 个实际服务位置照顾等待最久的候选，跨会话保存轮转。此排序是待使用验证的产品策略。

实际回忆尝试或有实质内容的教学才推进服务位置，刷新或取消未开始任务不推进。更新轮转不能偷偷改写记忆模型的 due。新词只使用剩余容量，用户也可明确调整当次分配。

## 什么算有效证据

| 情况                               | 保存与评价                                            |
| ---------------------------------- | ----------------------------------------------------- |
| 明确目标在无答案帮助时正确回忆     | 保存独立成功，符合规则时采用 Good                     |
| 有效测验中无法回忆，随后请求揭晓   | 保留首次失败；后续照写不覆盖 Again                    |
| 教学阶段主动提供答案或词库         | 保存支持下练习，不仅因帮助而判 Again，也不记独立 Good |
| 翻译使用正确同义词，未要求指定用词 | 翻译可成功；未测到的目标词不更新                      |
| 目标词正确但其他语法有错           | 分别反馈，仅更新有明确证据的能力                      |
| 题干或批改不确定                   | 待核对，不惩罚或提升记忆状态                          |
| 尚未打开、未作答或离开             | 未测，不更新                                          |

帮助需要在发生时记账，包括点词揭晓和聊天中展示当前答案。不能仅靠阶段小结回忆是否给过提示。评分修正保留版本，按原始作答时间重算，迟到结果不能覆盖新题或重复结算。

## 资料与后续扩展

词表决定范围和优先级，词典提供义项、音标和词形。首批计划从 NGSL 1.2 或已选核心范围整理 30～50 个核对过的词义；牛津核心词表可作为分阶段参照，不把公开浏览等同于整部词典的分发授权。

NGSL、Wiktionary / Kaikki 与 ECDICT 是候选来源，采用前检查具体文件、字段、质量和许可，保留版本与署名。AI 自拟例句、解释和词典原文分别标注；缺失的音标不编造成权威数据。词库未收录的输入显示待查，合法词形先关联词目，不能一律标红。

语音本轮延后，后续单词录音与句子 TTS 分开接入和缓存。没有音频仍能完成核心学习。

未来材料 Skill 可从用户提供的 PDF、文章或句子整理目标与计划。平台需要提供文件登记、解析、来源定位、计划预览和受控启用。重复材料复用原词义历史，词根与句式需要各自的测量规则，不能直接套作单词拼写卡或读完即记 Good。

## 科学依据与待验证参数

间隔练习、主动提取和纠正反馈具有研究支持；接触次数值得记录，但没有“每个词见十次就长期掌握”的统一门槛。理解与产出能力不同，母语释义可帮助初学者。具体组大小、交错顺序、补测次数与 AI 教学流程仍是需要跨日使用验证的设计。
