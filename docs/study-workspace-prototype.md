# 学习工作区交互原型

日期：2026 年 11 月 4 日；交互规则修订：2026 年 11 月 6 日。

本轮先验证学习页面是否顺手，重点是复习卡片和整批拼写循环。首页的 D0 真实备课能力继续保留；新页面使用独立的公开演示词组，不读取个人学习记录、不写入数据库、不调用模型，也不计算真实复习日期。

这是 [Demo 实施计划](demo-plan.md)中的界面验证步骤，不代表完整 D1 自助背词、D2 动态复习或 D3 AI 教学已经完成。正式产品规则见 [product.md](product.md)。

## 入口与页面布局

首页「开始学习」进入 `/study`，默认包含五个复习词。`/study?review=none` 用来体验没有待复习词的情况。

| 场景   | 顶部阶段                      |
| ------ | ----------------------------- |
| 有复习 | 复习 → 学习 → 句子练习 → 小结 |
| 无复习 | 学习 → 句子练习 → 小结        |

阶段使用一个个圆点和短标签表达，桌面端放在顶部品牌与右侧导航之间，当前阶段突出显示；没有复习时，学习就是第一个圆点。窄屏可在同一页头内换行，避免阶段条挤压品牌或导航。回忆词义、拼写、错词巩固属于复习内部步骤，不再增加顶层阶段。

视觉沿用首页的浅奶油色背景、绿色强调和圆角卡片。标题区、底部操作区与卡片提示的上下间距保持紧凑，让单词主体获得更多空间。主区域随视口变化，顶部阶段与底部操作保持可见，卡片区域单独滚动。桌面右侧常驻细长聊天面板，聊天历史独立滚动，输入区保持可见；窄屏需调整布局，不能靠固定像素高度或整页长滚动承载学习流程。

首页和学习页的页头均已接入主题选择，支持「跟随系统 / 浅色 / 深色」，首次默认跟随系统。浅色沿用原有配色，深色覆盖卡片、状态、输入和聊天区。偏好仅保存到当前浏览器，支持刷新恢复与同源标签页同步；切换主题不会重置当前页面的演示进度或输入草稿。

页头「显示设置」同时提供持久化的简约模式：隐藏整段 `study-intro` 标题与说明、装饰性小标题、聊天介绍等辅助引导文字，关闭后恢复。真实错误、暂停、轮次、进度、演示未保存及 AI 未连接等必要提示始终保留。简约模式只改变显示，不重置自评、轮次、单卡练习或聊天草稿。普通控件使用 2px 焦点圈与 2px 间距；主题选择和聊天组合输入框由外壳显示单圈，内部选择框与文本框不重复绘制焦点。

回忆页面不重复显示「回忆词义 x/5」「没有倒计时」或卡片内的「已翻开 · 可修改自评」等提示。自评按钮、卡片揭晓内容与底部进度承担状态表达；演示标识和刷新、切换流程、离页后清空的说明继续保留。

## 复习交互

每批约 5～10 个词是正式体验的初始设计；本原型固定五个演示词：apple、book、water、read、write。它们不是算法选出的到期词，也不表示用户实际欠下五个复习任务。

### 1. 回忆词义

卡片最初只显示英文，不显示中文或音标。先在心中回想意思，再选择：

| 自评 | 含义                               |
| ---- | ---------------------------------- |
| 遗忘 | 想不起来，或发现想的意思不对       |
| 模糊 | 能想到一些，但不确定或需要较久回想 |
| 清晰 | 很快、有把握地想起正确意思         |

「约 3 秒内想到」是清晰与模糊的个人参考，不倒计时、不自动判分。选择后卡片翻面展示中文，可以根据揭晓结果修正自评；再次点击已选项会取消自评并收起已揭晓内容。遗忘、模糊、清晰分别让整张卡片呈淡红、淡黄、淡绿，浅色与深色主题均提供对应状态；文字和按钮选中状态继续表达含义。所有词都完成自评后，才进入整批拼写。

自评是用户提供的线索，不是客观正确率，也不能单凭「清晰」延长真实复习间隔。

### 可选单卡默写

复习卡选择任一自评后、新词卡标记「记住了」后，才显示单卡默写图标。练习面将中文释义放在输入框上方，底部左侧是「返回」，右侧是「确定」。空白也可以提交，未答或答错时显示正确拼写。结果区预留一行，练习面保留打开前的卡片高度，较长的释义可以换行。可编辑输入再次确定，也可返回查看词卡并修改标记。

单卡输入不加入整批轮次、整批首答或已通过统计，也不证明掌握，不替代全批自评或新词整组总拼写门槛。它和答案揭晓都属于额外支持练习；原型仍只保留本页内存状态，不向数据库保存或生成独立 Good。

### 2. 整批拼写

每张卡片显示中文释义、音标和输入框，不显示英文答案。用户可以逐卡输入，也可以明确选择「不会」，最后一次提交整批。

- 输入过程中不显示对错，不逐词提交后立即揭晓。
- 空白表示未作答，必须补充输入或选择「不会」后才能提交，不能自动记成遗忘。
- 本原型拼写比较忽略首尾空白和大小写，但保留用户原始输入；词形、同义词与题目歧义的完整规则留待真实测验接入。
- 整批提交后才产生本页的这一轮记录，未提交草稿不算作答。

### 3. 错词巩固与下一轮

正确词从活跃卡片中收起，显示本轮累计已通过数量。错误词继续留在卡片区，展示「原始回答」与正确拼写；选择「不会」也保留这一事实。

逐个确认「记住了」后，点击开始下一轮：隐藏答案、清空输入、打乱剩余错词，再进行整批拼写。只有一个错词时无法改变顺序，也不能靠立即重输证明长期记忆。

后续轮次只重测复习中的剩余错词，已通过词不重新加入。每次提交都追加新的轮次，不能用第二轮的正确答案覆盖首轮错误。

纠错阶段允许将某个词「暂缓」。暂缓词从本次活跃列表移出，单独计数，不加入已通过列表。最后一个词被暂缓时，本批可以结束，但不得显示为全部通过。用户也可以暂停本页流程，稍后在当前页面继续；不以无限循环作为离开条件。

## 数据与测量边界

原型只在 React 页面内存中保存操作。暂停保留当前自评、输入草稿和已提交轮次；暂停期间不能推进作答。刷新、关闭、返回首页或切换演示场景会重置原型。页面需要明确说明这一点，不宣称支持跨日恢复或数据已经保存。

复习演示状态包含当前自评、活跃词、输入草稿、明确不会、已通过、暂缓、已确认记忆、当前步骤、暂停状态，以及每轮记录。每轮记录包含轮号与各词的原始答案、是否选择不会、当轮是否拼写正确。首答和首次拼对的轮次可以从这些记录追溯。

当前原型不实现完整事件时间线、用户身份、原始自评修改历史、帮助记录或服务端持久化。接入真实学习时必须补齐这些事实与保存回执，并保存单卡默写的额外原始输入、比对和答案揭晓，记为支持练习与最近曝光，不能据此产生独立 Good。不能将这份内存状态直接当作唯一学习账本。

词义回忆阶段已经展示过英文，后续拼写又提供音标，因此这轮成功首先是支持条件下的巩固结果。原型不生成 FSRS 的 Good / Again，不生成记忆概率，不把反复纠正记成多次独立成功。正式调度需要另行满足[测量规则](measurement-rules.md)的题目、时间和帮助条件；页面上的「通过」只描述本次演示拼写结果。

## 学习、句子练习与小结的范围

本轮的新词阶段提供 house、room、door、chair、table 五张演示卡，包含词性、音标、简释和简单中英例句，并可标记或撤销记住。默认观看、心中回忆和自评，不进行实时 AI 干预；标记记住后可主动使用上述单卡默写。

本轮没有实现新词总拼写。进入句子练习使用明确的预览入口，不表示已经通过正式学习门槛。正式实现仍须遵循：全组自评后才总拼写，后续每轮重测整组，不能复用「只重测复习错词」规则冒充新词过关。

句子阶段提供简单英译中草稿体验，不做 AI 批改或真实评分。小结展示本页复习操作、自评、轮次和暂缓信息；新词浏览、翻译草稿或查看小结都不代表完成真实学习任务。

右侧聊天区用于确认输入与阅读体验，明确标记尚未连接陪伴 Agent。本页可以试输入消息，但它不会发送给 Codex，不提供固定回复假装 AI 已作答。切换学习阶段不应要求用户到另一个窗口聊天。

## 演示材料来源

词义和音标沿用项目已核对的种子词条，来源为 Wiktionary contributors，词汇数据按 CC BY-SA 4.0 提供；修订链接、处理方式及许可见[词条来源](lexicon-sources.md)。前端文件中的词组是公开演示夹具，不是从真实用户测验泄露的参考答案。

例句是人工整理的演示内容，不冒充本次 Agent 实时生成，也不作为小说原文引用。

## 下一步：将学习页接入 Codex CLI

D0 已经有 Node.js → Codex App Server → 学习 MCP 工具的真实备课链路，首页继续使用它。本轮之后要打通的是新学习工作区与陪伴会话的交互，复用已有运行时，不另建一套 Agent。

下一轮先做最小闭环：网页提交一条聊天消息，Node 保存并关联当前学习会话，唤起或续接 Codex 轮次，再把公开进度与文本事件送回同一个聊天区。断线、失败、停止与重试有明确状态；后台不靠模型轮询等待用户输入。

之后再接真实学习快照与动作保存：算法给出需要学和复习的目标，网页提交自评、整批答案、暂停和暂缓，服务端保存原始事实并返回回执。Agent 查询这些记录，准备后续课程与反馈；它不能通过自然语言直接修改成绩或跳过门槛。

出题与陪伴角色可以逐步拆分。第一步优先验证一个真实会话在网页里收发顺畅，再补充两个角色的上下文关联、结构化出题、帮助记账和阶段小结。新词观看与总拼写循环仍由平台执行，不增加逐卡模型调用。

## 本轮验收范围

实现验收应覆盖以下实际操作；通过这些检查不等于真实调度或 Codex 聊天已经验收：

1. 首页可进入独立学习页；无复习场景第一点为学习。
2. 词义未自评时不揭晓，全部标记后才能进入拼写；可修正自评。
3. 拼写不实时判分，空白不能提交，明确不会可提交。
4. 首轮正确词收起，错词显示原答与正确拼写；确认后仅剩余错词进入新一轮，原记录保留。
5. 暂缓不计通过；暂停后在本页继续，草稿与轮次仍在。
6. 新词与句子区域清楚标记预览，聊天明确未连接；原型操作不写数据库、不调用模型。
7. 主要操作与聊天输入可达；卡片、聊天的滚动不把整个学习工作区推离视口。
8. 行为测试、类型检查、lint、构建和浏览器交互检查通过。
