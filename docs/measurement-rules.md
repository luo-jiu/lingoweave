# 第一版测量规则

规则版本：`d0-v1`。实现位于 `apps/server/src/measurement.ts`，为纯函数 `classifyMeasurement`。D0 已有分类器与回归样例，网页备课接口不调用它、不产生学习成绩。mini 的显式独立拼写检验已由调用方使用该分类结果接入 FSRS；分类器本身不更新调度。

2026 年 11 月 17 日的 [新流程与后台评价](learning-flow-rules.md)已使用独立的 `mini-flow-scheduling-v1` 适配层。本文件前半部分继续定义未改变的 `d0-v1` 独立证据资格；新版完成、自报复习与模型判断均保留各自来源，不改称客观独立测量。

本规则判断“一次作答能否作为独立回忆证据”，不负责比较拼写、批改翻译或判断长期掌握。调用方先保存原始事件，再提供客观评分、帮助事实和实际时间；返回结果保留事件身份、目标义项、能力、作答时间、分类原因与生效的完整规则参数。

## 输入事实

- `eventId`、`targetId`、`ability`：一次事件、词义对象和本次检验的能力。`meaning` 与 `spelling` 各自记录；一个成功不能自动代表另一能力成功。
- `kind`：观看、自评或实际尝试。观看和点击“记住了”不属于客观检验。
- `occurredAt`：实际作答提交时间；`evaluatedAt` 由调用方传入分类时的可信时间。时间必须是带时区的有效 ISO 日期。后台批改延迟不能延长这次作答的回忆间隔。
- `answerProvided`：明确是否已经提交答案；未提交或缺失该事实按未测量处理。不会把退出、空缺或没有来学习写成失败。
- `outcome`、`assessment`：`correct` / `incorrect` 和 `objective` 才构成当前版本可采用的评分。无评分或未核对的语义评价保持待核对；AI 自称正确不等于客观评分。
- `help`：本次作答过程中是否显示答案或提示。明确 `none` 才可能独立；`present` 表示受支持，缺失或 `unknown` 表示待核对。
- `lastAnswerExposureAt`：这次作答之前最近一次看到目标答案的实际时间。明确 `null` 表示已经确认没有此前答案暴露；缺失表示不清楚，不能按“从未看过答案”处理。作答时仍显示答案由 `help: present` 表示。
- `interveningOtherTarget`：最近答案暴露到本次作答之间，是否确实处理过其他目标。调用方根据已保存事件计算，不能由模型凭印象填写。

调用方负责输入对象身份和范围校验，分类器不修改原始输入或保存数据库。对同一事件重算时，应另存评分版本及规则参数；不能覆盖首答或把一次订正变成此前的独立成功。

## 分类顺序

| 分类                  | 条件与含义                                                           |
| --------------------- | -------------------------------------------------------------------- |
| `pending_review`      | 时间无效、作答在分类时间之后，或答案暴露在作答之后；不能据此评分     |
| `unmeasured`          | 观看、自评，或没有明确提交答案                                       |
| `pending_review`      | 已作答但尚无客观评分、帮助情况未知，或无帮助但此前答案暴露情况未知   |
| `supported`           | 有客观评分且明确在答案或提示支持下作答；正确与错误都保留为支持下练习 |
| `too_soon`            | 答案已隐藏且明确无帮助，但距最近答案暴露的间隔尚不满足下面的规则     |
| `independent_success` | 可采用的独立回忆，客观评分正确                                       |
| `independent_failure` | 可采用的独立回忆，客观评分错误                                       |

不满足证据条件时，不因结果写错就自动分类为独立失败。来源时间不一致即使同时出现帮助标记，也先待核对。

## 默认间隔

`minRecallDelayMs = 60_000`，`minSoloRecallDelayMs = 300_000`。

如果确认此前未见过该目标答案（`lastAnswerExposureAt: null`），一次明确无帮助、已客观评分的首测可以直接成为独立证据。

如果有此前答案暴露，则必须从**最近一次暴露到实际作答**至少经过 60 秒，并满足以下任意一项：

1. 期间确实穿插过其他目标。
2. 期间已过去至少 5 分钟，适用于只练一个目标或没有穿插记录的场景。

60 秒与 5 分钟均包含边界值。一次新的揭晓会重新确定最近暴露时间。暂停跨会话不清零时间；回来后按原事件时间计算，而不是按打开页面的次数计算。

这些数值是可复验的首版产品启发式，不是科学上适用于所有人的最佳间隔，也不能证明长期掌握。研究支持间隔与提取练习，但这两个具体阈值仍需要实际使用评估。改变数值时记录完整参数并更新规则版本，保留旧事件和旧判定。

## 验收样例

| 已保存的实际情况                                   | 分类                                                     |
| -------------------------------------------------- | -------------------------------------------------------- |
| 只看卡片或点击“记住了”                             | `unmeasured`                                             |
| 首测明确无帮助、此前未暴露答案，拼写正确           | `independent_success`                                    |
| 相同条件下首测拼写错误                             | `independent_failure`                                    |
| 刚揭晓答案就照着输入正确答案                       | `supported`；若答案已隐藏但立即输入，则为 `too_soon`     |
| 五词组中 A 揭晓后穿插 B/C，60 秒后无帮助正确写出 A | `independent_success`                                    |
| 只练 A，答案隐藏后暂停 4 分 59 秒再正确写出        | `too_soon`                                               |
| 只练 A，答案隐藏后暂停 5 分钟再无帮助正确写出      | `independent_success`                                    |
| 不知道聊天或点词是否暴露过答案                     | `pending_review`                                         |
| 首答错误，随后看答案订正正确                       | 首答保留 `independent_failure`；新订正事件为 `supported` |
| 作答时只隔 1 秒，第二天才完成批改                  | 仍为 `too_soon`                                          |
| 空缺、退出或未提交答案                             | `unmeasured`，不制造失败                                 |

本分类不映射 FSRS 的 Good / Again，也不单独结算整组过关。后续服务应结合原始题目、请求去重、评分版本和阶段规则采用证据；不能把所有短期独立成功机械转换成多次长期熟练记录。

## 新流程的完成与调度评价边界（已实现）

新词完成由三阶段记忆通过、全组拼写阶段结束和本词翻译确认决定。拼写第三轮首答失败仍可继续翻译，后台评价尚未返回不影响完成数；复习重学不增加新词数。完成、支持练习和长期掌握是不同事实。窗口的初选、展开、记错、下一词确认分别保存，只有确认推进阶段；首答及订正始终分开。

新版 `mini-flow-scheduler.ts` 为词义与拼写分别维护 FSRS-6 卡。以下采用规则不会改变 `classifyMeasurement`：

| 事实来源                   | 当前采用方式                                                      | 证据边界                                                                                                                                                           |
| -------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 复习初见清晰、模糊、遗忘   | meaning 分别采用 Good、Hard、Again                                | 来源为 `self_report`，不能称为客观测验；后续重学不覆盖首次判断                                                                                                     |
| 初选前已有聊天、音频等帮助 | 清晰/模糊不追加回忆成功，安排较近复习                             | `beforeJudgmentCount` 区分同一时间戳的答前帮助与答后朗读；普通复习英文已显示时的 `audioKind: word` 只记拼写曝光，不额外算 meaning 帮助；句子及旧未知类型仍保守处理 |
| 复习拼写原始首答           | 满足已保存帮助和间隔条件才采用 spelling Good/Again                | 订正、近期照写或帮助后作答只作支持练习；不能重复累计独立成功                                                                                                       |
| 后台翻译评价               | 分别采用目标词义与目标拼写；只有固定证据资格允许才生成 Good/Again | 拼写能力只对中译英开放；未测到、不确定维度不产生独立评分，模型来源仍记为 `model`                                                                                   |
| 新词完成但尚无合格评价     | 能力卡可为空，词级排期仍设为下一自然日                            | 不为了初始化曲线伪造 Good；同日 probe 或正面 AI 不取消首次次日复习                                                                                                 |

翻译提交时，学习库事务固定原题、原答、提交时间以及当时的窗口事件、拼写原答、帮助、历史和资格，保存为评价草稿。下一题确认时再固定确认时间及截至此时的相关讨论，生成持久 outbox；答后讨论不能替换原答或倒写答前资格。旧作答缺少提交时快照时按不具备独立资格处理。

背景评价仅读取冻结输入，返回 meaning/spelling/usage 的 correct、incorrect、not_tested 或 uncertain 和具体证据引用。平台保留完整输入、结果、实际模型配置、规则/Skill/提示哈希与采用回执。程序决定是否采纳及排期，AI 不提交 due。任务队列逐题处理，下一题继续；首页展示待处理和重试。任务失败、模型迟到或进程重启不会增加新作答。

### 支持错误的保守安排

未达到独立资格的错误不伪造 `independent_failure`，也不直接把支持下失败写成 FSRS Again。它们仍有教学价值，当前通过初学间隔上限影响下一次巩固：

| 已保存事实                                       | 首次真实复习之后的间隔上限 |
| ------------------------------------------------ | -------------------------- |
| 至少一次记忆错误或拼写首答错误                   | 2 个自然日                 |
| 记忆累计至少三次错误，或拼写三轮首答错误         | 1 个自然日                 |
| AI 明确指出目标词翻译拼写错误且无整体不确定项    | 1 个自然日                 |
| AI 明确指出其他目标词义/用法错误且无整体不确定项 | 2 个自然日                 |

多个上限取更近者；第二次实际复习解除初学上限，由随后实际证据继续更新。首次复习依旧安排在完成后的下一自然日。三轮复习仍不清晰或本次拼写有首答错误，也可直接触发次日复习。这些是可追溯的产品保守策略，不是研究验证的最优参数；不制造重复失败次数，不把其他单词或纯风格问题当作目标词遗忘。

### 迟到结果与可追溯范围

调度按事件实际发生顺序重放，评价使用原确认时间而非模型返回时间；后来的真实复习仍留在其正确位置。能力状态、词级 due、次日约束、初学上限和有界负荷错峰一起重算，每次采用保存前后值、理由及参数。已采用输入与结果不能被重试覆盖，同一来源不会重复结算。

当前已实现失败重试、崩溃对账、迟到结果和只读追溯；尚未实现已采用评价修订、输入副本清理或多题合并评价。完整交互与证据规则见 [评分追溯](learning-flow-rules.md#6-评分追溯保留什么如何使用)，实际实现与测试入口见 [架构](architecture.md#新窗口与后台评价)。
