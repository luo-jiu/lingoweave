# 首批词条的来源与使用范围

数据版本：`LingoWeave seed v1`，核对日期：2026 年 11 月 3 日。

首批种子包含 30 个日常英语词义，覆盖食物、家庭与学校、常用动作和简单形容词。D0 第一组固定采用 apple、book、water、read、write。排序是验证备课链路的产品选择，不是频率排序、水平测评或复习算法的输出；本种子也不宣称是 NGSL、考试大纲或任何商业词典的正式词表。

## 数据来源与许可

来源为 **Wiktionary contributors（维基词典贡献者）**。通过英文 Wiktionary 的 MediaWiki API 读取每个词条的 English 段，记录实际修订 ID，并核对所选义项、词性与音标。每条记录的 `sources.url` 指向该修订的 English 段，`sources.version` 同时保留上游修订号和本地种子版本。页面历史可以沿该链接继续查询贡献者。

获取时，站点 `siteinfo/rightsinfo` 返回 [Creative Commons Attribution-Share Alike 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.en)。这批改编的词汇数据按 **CC BY-SA 4.0** 提供；再分发或改编时须保留贡献者、来源、许可及修改说明，并遵守相同方式共享条件。这一说明适用于词汇数据，不为整个项目代码另行指定许可证。

来源查询入口：[英文 Wiktionary API 的许可信息](https://en.wiktionary.org/w/api.php?action=query&format=json&meta=siteinfo&siprop=rightsinfo)。运行应用时直接使用随项目提供的种子，不需要每次访问词典网站。

| 字段                    | 来源与处理                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| `id`                    | 项目分配的稳定义项身份，如 `en:apple:noun:fruit`；不含来源修订号，也不因更换计划而改变                       |
| `lemma`、`partOfSpeech` | 根据所链接修订的 English 词条与相应词性核对                                                                  |
| `meaningZh`             | 项目为初学者编写的简短中文义，参考选定义项整理；属于编辑改写，不是 Wiktionary 的中文原文，也不是商业词典释义 |
| `phonetic`              | 从相同修订中选取一个实际出现的 IPA 音位转写，保留原有符号；没有核对依据时允许为 `null`                       |
| `sources`               | 贡献者、修订链接、许可和本地数据版本；客户端展示词条时应保留可访问的来源入口                                 |

未收录上游整条英文释义、音频文件、例句库或其他义项。后续 Codex 生成的例句单独标为 AI 自拟，不能继承词典来源标签。

## 义项与音标选择

每个词目前仅有一个学习义项。`read` 使用动词原形的 `/ɹiːd/`，不将过去式 `/ɹɛd/` 混入；`house` 使用名词的清辅音结尾读音。`book` 选择上游明确标注 RP/GA/AU 的 `/bʊk/`，而非地区性的 `/buːk/`。

多数词选取来源中标注 RP（传统英音）或多口音共用的读音；`teacher` 采用来源标注 GA 的读音，`student`、`table` 等保留上游的音节辅音表示。现有单个 `phonetic` 字段不是完整英美发音词典，页面不应统一标注为“英式音标”。同一个词的其他标准读音仍可能正确。

## 后续扩展

这是一份经过来源核对的小型初始资料，不具备完整词典的覆盖面或专业词典编辑保证。后续修订可新增发音地区、允许词形、上游义项定位与审校状态；已发生的学习记录继续关联原有稳定 ID，不能因更新中文简释而重新创建记忆历史。

扩展到其他词表时，应独立记录词表来源和版本，再关联这些词典义项。未知词、缺失音标和待核对解释需要如实显示，不能由模型生成后直接标成权威词典数据。
