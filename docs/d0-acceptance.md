# D0 验收记录

日期：2026 年 11 月 3 日。范围：固定五词组的真实 Agent 备课、材料提交与保存恢复。此记录不代表 D1 背词、D2 复习或 D3 陪伴教学已经完成。

## 当前实现

- 30 个 Wiktionary 来源词义，带修订链接、许可与中文改写说明；固定组为 apple、book、water、read、write。
- Node.js 自带 SQLite、版本 1 迁移、单进程数据目录锁、备课任务、材料、公开消息、事件和请求回执。
- 网页启动、停止和重试备课；运行时状态与模型选择；SSE 事件通知和工作区快照恢复。
- Codex App Server stdio 接入、`lesson-author` Skill，以及 `learning_get_context` / `learning_publish_materials` 两个学习工具。
- 第一版测量分类器与回归样例。备课不调用分类器，不产生学习成绩。

## 已确认的协议证据

实际 Codex CLI 为 `0.153.4`。独立 App Server 已完成初始化、登录状态读取、模型列表读取与线程工具范围探测；实际适配器 `status()` 也返回可用且已登录。验证时默认模型为 `gpt-6.1-sol`，选择来自运行时列表。

已确认空 `mcp_servers` 表会与用户配置合并，因此实现显式停用继承条目，并在轮次开始前验证只有当前学习 MCP 连接。只读线程与所需工具连接已实际探测；没有修改用户全局配置。

桥接和传输的 14 项独立测试已通过，覆盖响应关联、分段 UTF-8、无效或超限数据、子进程退出、超时、授权请求、模型不可用、工具范围、公开消息去重及取消。该阶段后端类型检查和桥接 lint 已通过。

协议依据：[App Server 官方文档](https://learn.chatgpt.com/docs/app-server)、[MCP 官方文档](https://learn.chatgpt.com/docs/extend/mcp)。D0 使用临时线程并保存其身份；重试从平台记录重建上下文，不宣称具备持续线程恢复。

## 真实备课结果

浏览器发起首次准备后，实际任务完成：`attempt = 1`，模型 `gpt-6.1-sol`，已保存线程身份。SQLite 只读核对显示 `learning_get_context` 与 `learning_publish_materials` 各调用一次，保存五条材料，共记录 17 个事件。网页捕获并展示了公开回复流，消息同时持久化。

本次自拟例句为 “I eat an apple.”、“This book is new.”、“I drink water every day.”、“I read at home.”、“I write my name.”，分别覆盖固定组五个目标。材料均有中文翻译和 AI 自拟标记，词条来源入口保留。
