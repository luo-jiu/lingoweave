# 英语学习调度机制验证

日期：2026 年 11 月 2 日。

本目录是研究验证材料，不是学习应用。使用 ts-fsrs 5.4.2 和 FSRS-6，在预设作答历史上验证时间、评分和队列规则；不能据此证明学习效果或个人记忆概率的准确性。

使用兼容的 Node.js 20 以上版本，在本目录运行：

```sh
npm ci --ignore-scripts --no-audit --no-fund
node probe.mjs
```

脚本会核对机制断言，并重写 probe-results.json。原始执行环境为 Node.js 22.22.0。未附带 node_modules；锁文件固定了依赖版本及完整性校验。

分组和队列部分为最小规则样例，不覆盖应用界面、持久化事务、网络并发或真实 AI 批改。
